NapCat is a modern, protocol-side QQ bot framework built directly on NTQQ. It exposes the full [OneBot 11](https://onebot.dev/) standard — plus dozens of extended actions — over HTTP, WebSocket, Server-Sent Events, and a plugin transport. Set up your bot in minutes using the built-in WebUI, then connect any compatible bot SDK to start automating QQ groups and chats.

## How NapCat works

NapCat loads as a plugin inside NTQQ (Framework mode) or runs alongside it as a separate process (Shell mode). Either way, it intercepts QQ's internal NTQQ session and exposes a clean, standards-based API to your bot logic.

<Steps>
  <Step title="Install NTQQ and NapCat">
    Download NTQQ for your platform, then place the NapCat release alongside it. No build tools required — NapCat ships pre-compiled.
  </Step>
  <Step title="Log in via WebUI">
    Open the built-in WebUI at `http://127.0.0.1:6099/webui` to scan the QR code or use quick-login with an existing session.
  </Step>
  <Step title="Configure a network adapter">
    Add an HTTP server or WebSocket server in the WebUI (or edit `network.json` directly) so your bot can receive events and call actions.
  </Step>
  <Step title="Connect your bot framework">
    Point any OneBot 11–compatible framework (AstrBot, Nonebot2, Koishi, etc.) at NapCat's address. Send a `get_login_info` call to verify the connection.
  </Step>
</Steps>
