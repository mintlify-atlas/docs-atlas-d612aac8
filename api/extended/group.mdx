NapCat provides a rich set of group-management actions that complement the core OneBot 11 group API. These cover personal group remarks, extended group info, batch member removal, sign-in tracking, join-request queues, AI voice generation, and even QQ Zone (Qzone) posts — none of which exist in the base OneBot 11 specification. They are implemented natively inside NapCat and require a NapCat endpoint to function.

<Note>
  All actions on this page are **NapCat extensions** and are not part of the
  OneBot 11 standard. They will not work with other OneBot 11 implementations.
</Note>

---

## `set_group_remark`

Sets a personal remark (alias) for a group that is visible only to the bot account — it does not affect the group's public name.

### Parameters

<ParamField body="group_id" type="string" required>
  The group number.
</ParamField>

<ParamField body="remark" type="string" required>
  The new personal remark text. Pass an empty string to clear the remark.
</ParamField>

### Response

Returns `null` on success.

### Example

<CodeGroup>

```json Request
{
  "action": "set_group_remark",
  "params": {
    "group_id": "123456789",
    "remark": "Dev team chat"
  }
}
```

```json Response
{
  "status": "ok",
  "retcode": 0,
  "data": null
}
```

</CodeGroup>

## `get_group_share_link`

Generates a shareable invite link for the group. By default NapCat returns a short `qm.qq.com/q/...` URL. Set `need_short_url` to `false` to receive the full `qun.qq.com/universal-share/share?...` URL instead.

### Parameters

<ParamField body="group_id" type="number | string" required>
  The group number.
</ParamField>

<ParamField body="need_short_url" type="boolean">
  Whether to return a short URL (`qm.qq.com/q/...`). Defaults to `true`.
</ParamField>

<ParamField body="src_id" type="number | string">
  Internal share source ID. Defaults to `73`. You rarely need to change this.
</ParamField>

<ParamField body="additional_param" type="string">
  Optional additional query parameters to append to the link.
</ParamField>

### Response

<ResponseField name="url" type="string">
  The generated share / invite link for the group.
</ResponseField>

### Example

<CodeGroup>

```json Request
{
  "action": "get_group_share_link",
  "params": {
    "group_id": "123456789",
    "need_short_url": true
  }
}
```

```json Response
{
  "status": "ok",
  "retcode": 0,
  "data": {
    "url": "https://qm.qq.com/q/aBcDeFgHiJ"
  }
}
```

</CodeGroup>

## `send_qzone_msg`

Posts a new status update (说说) to the bot account's QQ Zone (Qzone). Supports plain text and multiple image attachments. Visibility is controlled by the `ugc_right` field.

### Parameters

<ParamField body="content" type="string" required>
  The text body of the Qzone post.
</ParamField>

<ParamField body="images" type="string[]">
  Optional array of image sources to attach. Each entry may be a
  `file://` path, an `https://` URL, or a `base64://` data URI. NapCat
  uploads each image automatically before publishing.
</ParamField>

<ParamField body="ugc_right" type="number | string">
  Visibility setting. Allowed values:
  - `1` — Everyone (default)
  - `4` — Friends only
  - `16` — Specific friends (requires `target_uins`)
  - `64` — Only me
  - `128` — Exclude specific friends (requires `target_uins`)
</ParamField>

<ParamField body="target_uins" type="(number | string)[]">
  Required when `ugc_right` is `16` or `128`. Array of QQ numbers that the
  visibility rule applies to.
</ParamField>

### Response

<ResponseField name="tid" type="string">
  The Qzone transaction ID (`tid`) of the newly created post. Use this value
  with `delete_qzone_msg` to remove the post later.
</ResponseField>

### Example

<CodeGroup>

```json Request (public post with image)
{
  "action": "send_qzone_msg",
  "params": {
    "content": "Hello from NapCat! 🐱",
    "images": ["https://example.com/photo.jpg"],
    "ugc_right": 1
  }
}
```

```json Response
{
  "status": "ok",
  "retcode": 0,
  "data": {
    "tid": "1234567890abcdef"
  }
}
```

</CodeGroup>
